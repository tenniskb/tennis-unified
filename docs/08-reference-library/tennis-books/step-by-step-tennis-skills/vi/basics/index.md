# Phần 1: Cơ bản

Chương nền tảng hỗ trợ mọi cú đánh trong cuốn sách. Nắm vững những nguyên lý này trước khi chuyển sang các kỹ thuật cụ thể.

## Các chương

1. [Phân tích chuyển động](analysing-movements.md) — ba giai đoạn của cú đánh
2. [Chiến thuật](tactics.md) — các khái niệm chiến thuật cơ bản
3. [Các yếu tố chung của mọi cú đánh](common-elements.md) — grip, ready position, follow-through
4. [Phân tích kỹ thuật cú đánh](breakdown-of-stroke-techniques.md) — cơ thể, tay, chân, điều phối

Mỗi chương xây dựng trên chương trước — đọc theo thứ tự để có chuỗi học tập sạch, hoặc nhảy thẳng đến khái niệm bạn cần xem lại.

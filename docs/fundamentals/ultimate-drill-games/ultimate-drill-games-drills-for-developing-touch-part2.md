# Ultimate Drill Games -Drills for Developing Touch-Part2

**Drills for Developing Touch:\
Part 2**

**Dave Hagler**

In the first article in the series I offered 4 simple drills to begin
developing touch and feel. [link](https://www.tennisplayer.net/members/ultimate_drillgames/dave_hagler/drills_for_developing_touch/part_01/)
Now here are 4 more slightly more difficult ones to continue players'
development.

|  | **Racket Toss and Catch** |
| --- | --- |
|  |  |
|  | Put the ball on the strings. Now toss it above your ahead and learn to catch it softly on the strings. Do it both palm up and palm down! |
|  |  |
|  | ![A person playing tennis Description automatically generated with medium |
|  | confidence](media_ultimate-drill-games-drills-for-developing-touch-part2/media/image1.webp) |
|  | **Hit and Catch** |
|  |  |
|  | Toss or hit a ball softly and ask the player to catch it on the racquet. Some players are predisposed to catch palm up with a forehand grip, others knuckles up with a backhand grip. The side they choose may |
|  | or may not correlate with their \"touch side.\" But work it both ways. |
|  |  |
|  | ![A person playing tennis Description automatically |
|  | generated](media_ultimate-drill-games-drills-for-developing-touch-part2/media/image2.webp) |
|  | **Bump and Slice** |
|  |  |
|  | This is a variation of the bump the ball drill from the first article. Bump the ball up a few times, then begin slicing as you bump. |
|  |  |
|  | ![A person playing tennis Description automatically generated with medium |
|  | confidence](media_ultimate-drill-games-drills-for-developing-touch-part2/media/image3.webp) |
|  | **All Slice** |
|  |  |
|  | When you can vary the bumps with the slice, progress to hitting all slice bumps. As you become more confident you can increase the amount of spin. |
|  |  |
|  | ![A child playing tennis Description automatically generated with low |
|  | confidence](media_ultimate-drill-games-drills-for-developing-touch-part2/media/image4.webp) |

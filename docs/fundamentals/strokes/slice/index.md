# Slice Fundamentals

Not every shot is about power. The slice disrupts rhythm, changes height, and controls pace. Touch shots run on constant firmness (4-5/10) — no gradient. Face locks early. Hua Jin — absorb and redirect.

## The Slice Q-V-ROOT-8-45-Impulse Map

| Variable | Name | Slice Implementation |
|----------|------|---------------------|
| Q | Quiet Eye | Eyes park early at contact zone |
| V | Vestibular | Head still — critical for slice (side-on) and disguise |
| ROOT | Rooting | Double Thực load; stable platform |
| 8 | Figure-8 | Tiny horizontal 8; no pause |
| 45° | Plane | 45°, high-to-low; edge leads, face follows |
| Brake | Impulse | No hard brake — soft absorption; Hua Jin transforms pace |
| Pulse | Fa Jin | Tiny pulse; firm hold, edge leads |
| Jin | Kình | Hua dominates; Ting feels incoming spin; Fa = minimal release |

## Slice: Backhand and Forehand

| Element | Backhand Slice | Forehand Slice |
|---------|---------------|----------------|
| Grip | Continental or Eastern backhand | Continental |
| Face | Slightly open (5-10°) | Slightly open (5-10°) |
| Path | High-to-low, outside-to-in | High-to-low, inside-to-out |
| Wrist | Firm extension, locked | Firm extension, locked |
| Contact | In front, on the side | In front, slightly across |
| Finish | High, across body | High, across body |
| Key | Non-dominant hand guides edge | Non-dominant hand rests on throat |

**Coach's Tip:** Slice error #1 = opening face too much → ball floats long. Fix: feel pinky edge leading. Face squares at contact naturally. Slice isn't "open face" — it's "edge leads, face follows."

## Fault Signals

| Shot | Symptom | Root Cause | Fix |
|------|---------|------------|-----|
| Slice | Floats long | Face too open | Pinky edge leads, face squares at contact |
| Slice | Into net | Contact late or low | Contact further in front, bend knees |

## Drills
1. **Slice wall:** 50 slices against wall — focus on edge leading, constant face, rhythm
2. **Touch circuit:** backhand slice, forehand slice, backhand drop, forehand drop, offensive lob — 5 reps each

**EDGE LEADS. FACE LOCKED. ABSORB. REDIRECT. DISGUISE.**

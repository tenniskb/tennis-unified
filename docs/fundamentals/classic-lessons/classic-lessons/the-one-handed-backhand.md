# The One Handed Backhand

### By Rich Berman

------------------------------------------------------------------------

In this new series, veteran teaching pro Rich Berman synthesizes a
lifetime of playing, studying the game, and teaching into a system for
developing every stroke. Rich breaks down the strokes into the simplest
possible progressions to create a strong technical foundation for
hitting both basic and advanced variations. In this article: the
one-handed backhand.

## How to Use This Section

The Mastery Manual is dense and long. It's not meant to be read once and finished. It's meant to be *worked* — read a section, take it to the court, come back the next week and reread the same section with fresh eyes.

The first read will feel like too much. The fifth read will feel obvious. That's the pattern with every deep reference document.
